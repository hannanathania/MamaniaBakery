# 🧁 Mamania Bakery

**Mamania Bakery** is a web-based e-commerce system developed in **2022** as a project for the **Object-Oriented Programming (OOP)** course.

The system is designed to simulate an online bakery store, allowing customers to browse products, add items to their cart, and place orders. It also provides an **admin dashboard** for managing products, inventory, stock, and customer orders.

## ✨ Features

### 🛒 Customer

* Browse available bakery products
* View product details
* Add products to cart
* Manage cart items
* Place orders
* View order information

### 📊 Admin Dashboard

* Manage bakery products
* Add, edit, and delete products
* Manage product stock and inventory
* Monitor customer orders
* Manage order information

## 🏗️ System Overview

The system consists of two main sides:

```text
Mamania Bakery
│
├── 👤 Customer
│   ├── Browse Products
│   ├── Product Details
│   ├── Shopping Cart
│   └── Order
│
└── 🔐 Admin
    ├── Product Management
    ├── Inventory Management
    ├── Stock Management
    └── Order Management
```

## 🛠️ Technologies

* **Programming Language:** Java
* **Database:** MySQL
* **Concept:** Object-Oriented Programming (OOP)

## 🎯 Project Objective

This project was created to apply **Object-Oriented Programming concepts** to a practical web application. Through Mamania Bakery, the project demonstrates how OOP principles can be implemented in an e-commerce system with different user roles and business processes.
